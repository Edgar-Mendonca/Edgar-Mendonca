# Other apps and prototypes

## Résumé analysis

A Flask app comparing a résumé with a job description: keyword match with TF-IDF and cosine similarity, readability
metrics and automatic summarisation. The summarisation module had been removed from the library version in use,
which broke the feature: pin versions, or replace removed modules.

## Document management

A simple document management system on static hosting: upload, metadata editing, a viewer in a new tab, delete and
browser storage, with a register of number, type, document number, title, revision, received, review and release
dates (dd/mm/yyyy) and reviewer. A browser-only login is not real authentication.

## HR system

An open-source HR system starting from a login and a simple list, to grow into richer functions and a better
interface.

## Thermowell wake frequency

A calculator for thermowell wake frequency (vortex shedding against the thermowell's natural frequency), the subject
of ASME PTC 19.3 TW.

## Book translation

A local Python app to translate a technical book page by page, where waiting longer for good output was fine. It did
not work in the end, and translation went back to chapter by chapter.
